🛠️ AI·rete·RAG – a Rete rule engine decides, RAG explains why

Summary
AI·rete·RAG is a system that combines a deterministic Python Rete rule engine for decision-making with a RAG pipeline and LLM for generating explanatory text. It ensures decisions are fully auditable while providing plain-English explanations that cite policy documents.

Why it’s interesting
It separates decision-making from explanation generation by running a deterministic rule engine before the LLM, preventing the LLM from altering verdicts.

Target user
Teams handling decisions that need to be auditable such as lending, fraud, clinical triage, insurance, and legal.

Business model
Hosted product with a free tier.
