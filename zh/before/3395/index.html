🛠️ Yantra – an LALR(1) parser generator for C++

Summary
Yantra is an LALR(1) parser generator for C++ that generates a lexer, parser, and AST walker from a single tool. It builds the entire AST first and then walks it top-down in a separate pass to run semantic actions.

Why it’s interesting
Unlike traditional tools that run semantic actions bottom-up during parsing, Yantra builds the whole AST first so parent actions can run before children are visited.

Target user
C++ developers
