🛠️ WebGCM – a global climate model running in the browser on WebGPU

Summary
WebGCM is a global climate model running in the browser on WebGPU that features a hydrostatic primitive-equation atmosphere on an icosahedral hexagonal grid. Users can visualize various atmospheric and oceanic fields, animate wind or currents, draw isobars, and view the globe under the model's own sun.

Why it’s interesting
It demonstrates a fully GPU-accelerated global climate model running directly in the browser, built using AI coding assistants over a single weekend.
