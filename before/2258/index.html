🛠️ EACL is a situated ReBAC authorization library for Datomic and Datahike

Summary

Why it’s interesting
It brings Google Zanzibar-style relationship-based access control directly into the application data layer to reduce network hops and maintain strong consistency.

Target user
Clojure developers building applications that require relationship-based access control.
