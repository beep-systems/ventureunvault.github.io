Summary
Vibivibi enables end-to-end encrypted sharing and syncing of local coding agent sessions across different machines or colleagues. Using a CLI tool, sessions are encrypted locally before being uploaded, allowing users to seamlessly resume their work elsewhere.

Why it’s interesting
It provides zero-knowledge, end-to-end encrypted storage and sharing for sensitive coding agent traces without letting the host read the contents.

Target user
Developers using local coding agents who need to continue sessions on different machines or share them securely with colleagues.

Business model
Freemium model offering free storage up to 200 MB, a Pro tier at $8 per month, and a Team tier at $15 per seat per month.
