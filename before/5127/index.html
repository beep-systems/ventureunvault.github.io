🛠️ Replacing CAPTCHAs with adaptive proof-of-work in WordPress

Summary
This project is a free WordPress plugin that replaces traditional CAPTCHAs with an adaptive proof-of-work approach using Hashcash to block spam bots. It uses pattern recognition on the HTTP post level to work with almost every web form and plugin combination while complying with EU data privacy laws.

Why it’s interesting
It uses an adaptive proof-of-work calculation to successfully block spam without cookies, external services, or running costs, and has reached over 4000 active installations.

Target user
WordPress site administrators seeking an EU data-privacy-compliant anti-spam solution.

Business model
Free open-source WordPress plugin under a GPL-2.0 license with no running costs.
