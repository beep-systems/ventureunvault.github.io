🛠️ The Kio Programming Language

Summary
Kio is a statically typed, hosted programming language designed to be ultra-portable, supporting eight host languages in version 0.1. It is based on polymorphic lambda calculus with higher-kinded types and relies on the host to supply capabilities instead of using built-in effectful functions or types.

Why it’s interesting
It features a minimalistic design with type-driven macros, higher-kinded types, and is designed with AI in mind while supporting eight host languages.
