🛠️ RDST – A local agent that watches Postgres/MySQL for query regressions

Summary

Why it’s interesting
It automates the traditionally reactive DBA process of catching query regressions and recommending fixes by combining local database monitoring with frontier AI models.

Target user
Developers and database administrators running Postgres and MySQL in production.
