🛠️ Rebuilding Amazon SES in Rust

Summary
NitroMTA is an open-source Amazon SES replacement written in Rust that maintains SES v2 API compatibility to let applications switch email infrastructure without rewriting code. It runs on bare-metal servers and includes features like IP budget tracking for warmups.

Why it’s interesting
It is an open-source drop-in replacement for Amazon SES written in Rust that claims significantly higher throughput than KumoMTA and Postfix in benchmarks.

Target user
Developers and organizations currently using Amazon SES who want to migrate to self-hosted bare-metal servers without rewriting application code.
