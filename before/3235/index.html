🛠️ Corral kill every command your agent starts

Summary
Corral is a command-line utility designed to ensure that AI agents and other runners completely terminate all processes they start, preventing dangling background jobs or timeouts that hang the runner. It uses cgroups and process tracking to clean up every process in the tree when the main command finishes.

Why it’s interesting
It addresses a common cleanup failure in AI agent runners where background processes or child trees survive or inadvertently kill the parent session.
