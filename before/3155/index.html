🛠️ Fusor – Like Vue, but the logic is Rust

Summary
Fusor is an experimental reactive web framework for Rust that compiles to WASM, using plain HTML files for templates instead of markup inside macros. State and logic are handled by ordinary Rust structs while leveraging Rust type checkers for HTML bindings.

Why it’s interesting
It offers a Vue-like development model where UI templates remain separate from logic without using macro-based markup inside Rust.

Target user
Rust developers building web applications
