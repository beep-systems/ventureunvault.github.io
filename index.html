🛠️ Minilith – A zero-dependency CMS stored inside a PNG file

Summary
Minilith is a zero-dependency database-free content management system where the entire state, including posts, pages, and settings, is compressed and stored inside the pixels of a PNG file using steganography. It relies on browser APIs to compress, secure, and render a micro blog directly from the image.

Why it’s interesting
It uses steganography to store an entire CMS and its database directly inside the pixels of a PNG file with zero external dependencies.
