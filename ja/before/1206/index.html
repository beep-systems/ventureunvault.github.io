🛠️ ToolJet – Claude Code and Codex build internal tools, no codegen

Summary
ToolJet is a platform that exposes its entire architecture over MCP, allowing coding agents like Claude Code and Codex to build internal tools without generating code. Instead of producing React or CSS, agents generate configurations for existing platform abstractions and components.

Why it’s interesting
The creators scrapped an 11-month-old multi-agent generation system to pivot toward an MCP-driven approach where external coding agents directly assemble internal apps using platform abstractions.

Target user
Developers and less technical users who build and maintain critical internal tools

Business model
API pricing for users without an existing coding agent subscription
