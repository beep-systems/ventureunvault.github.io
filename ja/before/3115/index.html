🛠️ Ppgrid – Rasterising points in minutes, not hours

Summary
Ppgrid is an open-source GIS tool designed to rasterise large-scale point data quickly using a modified Inverse Distance Weighting approach. It precalculates point and grid intersections to avoid traditional multiplicative scaling costs.

Why it’s interesting
It is significantly faster than existing IDW tools like gdal_grid or GRASS, processing millions of points rapidly.

Target user
GIS professionals and developers working with large-scale point data
